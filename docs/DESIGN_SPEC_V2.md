## 1. デザインコンセプト —「コードの深海に潜る」

参考にした構造: 竹書房「メイドインアビス」公式サイトのアビスガイドページ（層ごとに潜っていく縦構成・深度表示・層ジャンプ目次・図鑑的なカード・ダークで没入感のある画面）。

**著作権上の絶対条件**: 参考にするのは「層構造・深度メーター・図鑑性・ジャンプ目次」という**仕組みのアイデアのみ**。メイドインアビスの画像・キャラクター・ロゴ・固有名詞・音楽・特徴的な配色や意匠の模倣は**一切使わない**。世界観はこのサイトオリジナルの「深海探査」で作る。

- 世界観: 学びが深まるほど、コードの海を深く潜っていく。トップは海面（深度0m）、下にスクロールするほど深海へ。
- 全体はダークトーン基調（深海の紺〜黒のグラデーション）。ライトモードでも破綻しないこと。
- 泡・光の差し込み・微かな浮遊パーティクルなどの控えめな装飾はCSS/Canvasで自作。`prefers-reduced-motion` 時はアニメーションを止める。

## 2. 層構造（トップページの再構成）

トップページを「潜行ルート」として再構成する。各層はセクションで、層ジャンプ目次（コンパス風の固定ナビ）から直接移動できる。

| 層 | 名前 | 内容 | 深度表示の目安 |
|---|---|---|---|
| 海面 | ようこそ | ヒーロー。サイト名・キャッチコピー・「潜行開始」ボタン | 0m |
| 第1層 | あそぶ | ブラウザで遊べるゲームのハイライト（図鑑カード数枚＋「図鑑をひらく」） | 100m |
| 第2層 | よむ | ソースコード閲覧の紹介（コード画面のプレビュー＋対応作品数） | 300m |
| 第3層 | しくみをしる | 学習ページ（逆引きコード）の紹介。基礎/入門/応用の3段階 | 600m |
| 第4層 | つくる | 自分で作ってWeb化するまでの道のり（README/学習ページへの誘導） | 1000m |
| 最深部 | きろく | 活動アーカイブ（ゲームジャム・高大連携・年表）への入口 | 2000m |

- 各層に「この層でできること」の短いフレーバーテキストを置く（例: 第1層「まずは触れてみよう。すべてのゲームはブラウザで動く」）。
- 深度の数字は演出であり実データではない。

## 3. 遊び要素

1. **深度メーター**: 画面端（PCは右端、スマホは上部細帯）に現在のスクロール位置を「深度◯◯m」として常時表示。層に入ると層名も出る。
2. **図鑑スタンプ**: ゲーム詳細/プレイページを開いた作品に「発見済み」スタンプが付く。ゲーム一覧（図鑑）でスタンプ数「◯◯/34 発見」を表示。保存は `localStorage`（try/catchで包み、無効環境では単に表示しない）。
3. **実績バッジ**: 「はじめての潜行（初回訪問）」「はじめての発見（初プレイ）」「5作品発見」「10作品発見」「コードを読んだ」「全層到達（最深部までスクロール）」程度。达成時に控えめなトースト表示。localStorage保存。サーバー送信はしない。
4. **「ランダムに1本潜る」ボタン**: 図鑑とトップに設置。プレイ可能な作品からランダムに1つ選んでプレイページへ。
5. **浮上ボタン**: 「上に戻る」を「浮上する」と表記し、泡の演出付きで最上部へ。

## 4. 便利機能

1. **図鑑（ゲーム一覧）の強化**: 既存のフィルタ（活動・年度・カテゴリ・検索）を維持したまま、(a) プレイ可能のみ表示トグル (b) 並び替え（名前順・活動順） (c) 図鑑No.表示（データの並び順で自動採番）を追加。
2. **層ジャンプ目次**: 全ページ共通ヘッダーに「図鑑・活動・学習・About」への直リンク。トップでは層ジャンプ（海面〜最深部）も。
3. **キーボードショートカット**: `/` で図鑑の検索欄へフォーカス。Escで解除。それ以上は増やさない。
4. **共有**: 作品詳細ページに「URLをコピー」ボタン。
5. **パンくず**: 既存構造を維持。
