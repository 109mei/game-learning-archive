## 1. デザインコンセプト —「コードの深海に潜る」

参考にした構造: 竹書房「メイドインアビス」公式サイトのアビスガイドページ（層ごとに潜っていく縦構成・深度表示・層ジャンプ目次・図鑑的なカード・ダークで没入感のある画面）。

**著作権上の絶対条件**: 参考にするのは「層構造・深度メーター・図鑑性・ジャンプ目次」という**仕組みのアイデアのみ**。メイドインアビスの画像・キャラクター・ロゴ・固有名詞・音楽・特徴的な配色や意匠の模倣は**一切使わない**。世界観はこのサイトオリジナルの「深海探査」で作る。

- 世界観: 学びが深まるほど、コードの海を深く潜っていく。トップは海面（深度0m）、下にスクロールするほど深海へ。
- 全体はダークトーン基調（深海の紺〜黒のグラデーション）。ライトモードでも破綻しないこと。
- 泡・光の差し込み・微かな浮遊パーティクルなどの控えめな装飾はCSS/Canvasで自作。`prefers-reduced-motion` 時はアニメーションを止める。

### 1-1. 演出の強度（v2.2で明文化）

初版の実装は装飾が控えめすぎて「深海」が伝わらなかったため、次の強度を最低ラインとする。いずれも `prefers-reduced-motion` で停止・非表示にすること。

- **泡**: 海面だけでなく各層にも配置し、実機で視認できる不透明度にする（目安 0.35〜0.7）。層が深いほど数を減らし、ゆっくり昇らせる。
- **深度のウォーターマーク**: 各層の見出し脇に、深度の数字を大きく（clamp 56〜120px相当）薄く敷く。深度・数値表示は**等幅書体**（システム等幅）で統一する。
- **層境界**: 層の切り替わりに目盛り（ティック）付きの境界線を置き、潜っている実感を出す。
- **ビネット**: 深い層ほど画面周辺を暗く落とす。
- 図鑑カードは「発見済み」で見た目が変わること（既定）。加えて**未発見をシルエット表示にする任意設定**を用意する（3-6）。

## 2. 層構造（トップページの再構成）

トップページを「潜行ルート」として再構成する。各層はセクションで、層ジャンプ目次（コンパス風の固定ナビ）から直接移動できる。

| 層 | 名前 | 内容 | 深度表示の目安 |
|---|---|---|---|
| 海面 | ようこそ | ヒーロー。サイト名・キャッチコピー・「潜行開始」ボタン | 0m |
| 第1層 | あそぶ | ブラウザで遊べるゲームのハイライト（図鑑カード数枚＋「図鑑をひらく」） | 100m |
| 第2層 | よむ | ソースコード閲覧の紹介（コード画面のプレビュー＋対応作品数） | 300m |
| 第3層 | しくみをしる | 学習ページ（逆引きコード）の紹介。基礎/入門/応用の3段階 | 600m |
| 第4層 | つくる | 自分で作ってWeb化するまでの道のり（README/学習ページへの誘導） | 1000m |
| 最深部 | きろく | 活動アーカイブ（ゲームジャム・高大連携・年表）への入口 | 2000m |

- 各層に「この層でできること」の短いフレーバーテキストを置く（例: 第1層「まずは触れてみよう。すべてのゲームはブラウザで動く」）。
- 深度の数字は演出であり実データではない。

## 3. 遊び要素

1. **深度メーター**: 画面端（PCは右端、スマホは上部細帯）に現在のスクロール位置を「深度◯◯m」として常時表示。層に入ると層名も出る。
2. **図鑑スタンプ**: ゲーム詳細/プレイページを開いた作品に「発見済み」スタンプが付く。ゲーム一覧（図鑑）でスタンプ数「◯◯/34 発見」を表示。保存は `localStorage`（try/catchで包み、無効環境では単に表示しない）。
3. **実績バッジ**: 「はじめての潜行（初回訪問）」「はじめての発見（初プレイ）」「5作品発見」「10作品発見」「コードを読んだ」「全層到達（最深部までスクロール）」程度。達成時に控えめなトースト表示。localStorage保存。サーバー送信はしない。
4. **「ランダムに1本潜る」ボタン**: 図鑑とトップに設置。プレイ可能な作品からランダムに1つ選んでプレイページへ。
5. **浮上ボタン**: 「上に戻る」を「浮上する」と表記し、泡の演出付きで最上部へ。
6. **未発見シルエット表示（任意・既定オフ）**: 図鑑で未発見作品のサムネイルを伏せる表示を切りかえられる。既定はオフ（初見の閲覧性を損なわないため）。設定は localStorage に保存。
7. **発見率の可視化**: 図鑑の「探検記録」に発見数のプログレスバーを置く。
8. **記録のリセット**: 図鑑（および About からの導線）に「発見記録・実績を消す」ボタンを置き、確認のうえ localStorage の記録を削除できるようにする。トーストは**1件ずつ順に表示**し、同時に積み上げない。

## 4. 便利機能

1. **図鑑（ゲーム一覧）の強化**: 既存のフィルタ（活動・年度・カテゴリ・検索）を維持したまま、(a) プレイ可能のみ表示トグル (b) 並び替え（名前順・活動順） (c) 図鑑No.表示（データの並び順で自動採番）を追加。
2. **層ジャンプ目次**: 全ページ共通ヘッダーに「図鑑・活動・学習・About」への直リンク。トップでは層ジャンプ（海面〜最深部）も。
3. **キーボードショートカット**: `/` で図鑑の検索欄へフォーカス。Escで解除。それ以上は増やさない。
4. **共有**: 作品詳細ページに「URLをコピー」ボタン。
5. **パンくず**: 既存構造を維持。
6. **関連サイト**: 全ページ共通で、**フッターのすぐ上**に「関連サイト」セクションを置く。**サイト名＋1行紹介のカード形式**で、外部リンクとわかる表示にする（別タブで開く・`rel="noopener"`・カードにURLを併記）。掲載は下表の2件。URLは `site/src/data/site.json` から読み、**空欄のカードは表示しない**（2件とも空ならセクションごと非表示）という既存の方式を守る。フッター内の同じ外部リンク枠は引き続き併置してよい。

| サイト名 | URL（site.json のキー） | 1行紹介 |
|---|---|---|
| 永野斗遠 ポートフォリオ | `portfolioUrl` = `https://109mei.github.io/` | このアーカイブの制作者の業績・活動 |
| IDERIA公式サイト | `ideriaOfficialUrl` = `https://109mei.github.io/ideria-official/` | ゲームを生み出している制作団体 |

7. **絞り込み条件のURL反映**: 図鑑の検索語・絞り込み・並び替え・表示状態をクエリ文字列に反映し、リンク共有・ブックマーク・再読み込みで復元できるようにする（`history.replaceState`。履歴を汚さない）。
8. **検索対象の拡張**: タイトル・説明・ジャンルに加え、制作元・関連活動名・使用技術・活動種別も検索対象にする。並び替えの「名前順」は辞書順であることをラベルで明示する（データに読みを持たないため）。
9. **前後ナビ**: 作品詳細に図鑑No.順の「前の作品／次の作品」、学習トピックに番号順の前後リンクとパンくずを置く。
10. **発見状態フィルタ**: 図鑑に「未発見のみ／発見済みのみ」の絞り込みを追加（記録が使えない環境では出さない）。
11. **モバイル最適化**: 図鑑の絞り込みは「絞り込み」ボタンで開閉する（既定は閉、検索欄だけ常時表示）。ソース閲覧ページのファイル一覧は横スクロールの1行に収め、素材ファイルは折りたたむ。キーボード操作のヒントはポインタ環境のみ表示。
12. **共有・検索エンジン対応**: 各ページに OGP（`og:title`/`og:description`/`og:url`/`og:image`）と `twitter:card` を出力する。作品ページはサムネイルを、その他は既定画像を使う。`sitemap.xml` と `robots.txt` も生成する（いずれも `siteUrl` 未設定なら出力しない）。
13. **最終ビルド日**: フッターに「最終更新（ビルド）日」を表示する。データに追加日を持たないため、更新の目安として生成日を出す。
14. **実績棚の再掲**: About にも実績バッジの一覧を表示する（獲得状況は localStorage から反映）。

- レスポンシブ（スマホ幅〜PC）、ダークモード基調、コントラスト確保、キーボード操作可、画像alt。
