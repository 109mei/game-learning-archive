# SPECIFICATION.md — 機能仕様

## 1. 全体

- 静的サイトジェネレーター: **Astro**（Node 18+）。全ページ日本語。
- データ駆動: `src/data/` のJSONと `src/content/learn/` のMarkdownだけを編集すれば全ページに反映。HTMLの手編集は不要。
- ホスティング: GitHub Pages / Netlify / Cloudflare Pages いずれも可（無料枠で運用可能）。

## 2. 作品一覧 `/games/`

- ゲームカード: サムネイル（無ければ「画像準備中」プレースホルダー）・タイトル・短い説明・ジャンル・制作年度・制作元・使用技術タグ・「ブラウザで遊べる」バッジ。
- 絞り込み: 年度／活動種別（カテゴリ）／ジャンル／使用技術／ブラウザ対応／制作元。複数条件はAND。
- 検索: タイトル・説明・別名のインクリメンタル部分一致（クライアントサイドJS。ビルド時にJSONを埋め込み）。
- 並び: 新しい年度順（デフォルト）。

## 3. 作品詳細 `/games/<id>/`

表示項目（**値が null / "要確認" の項目は行ごと非表示**）:
タイトル／メイン画像／概要／操作方法／ジャンル／プレイ人数／制作年度／制作元／関連活動（リンク）／使用技術／スクリーンショット／制作背景／工夫した点／このゲームで使われている技術（学習ページへのリンク）。
主要ボタン: 「ブラウザで遊ぶ」（playable時のみ）・「ソースコードを見る」（source.available時のみ）。

## 4. ブラウザプレイ `/play/<id>/`

- pygbagビルド成果物は `public/play-files/<id>/` に配置し、プレイページから **iframe** で表示（サイト本体とゲーム実行を分離）。
- iframeには `allow="autoplay; fullscreen"` を付与。クリックで開始（音声のブラウザ自動再生制限対策）。
- 操作方法・注意書き（読み込みに時間がかかる等）・全画面ボタン・作品詳細へ戻るリンクを併設。
- 元ゲームは改変せず、Web対応が必要な修正は `web_versions/<id>/` のコピーに対して行う（詳細は WEB_COMPATIBILITY.md）。

## 5. ソースコード閲覧 `/source/<id>/`

- 左: ファイルツリー（.py等のテキストのみ。画像・音声はファイル名とサイズのみ表示）。
- 右: コード表示。**行番号・Pythonシンタックスハイライト（ビルド時にShikiで静的生成）・ファイル切替・コピー ボタン・折返し切替**。
- 表示するソースは `game-sources/<id>/` にコピーした公開確認済みファイルのみ（氏名を含むファイル名はリネーム済み）。編集機能は初期版では持たない。

## 6. 活動記録 `/activities/` ほか

- 一覧: カテゴリタブ＋年度絞り込み。カード表示（活動名・日付・場所・作品数）。
- 詳細: 名称／開催日／年度／概要／テーマ／参加人数／対象／制作形式／使用技術／**制作された作品（自動逆引き一覧）**／活動写真（公開確認済みのみ）／関連資料。null・要確認は非表示。
- ゲームジャム一覧 `/game-jams/`: 年度→開催回の階層表示。
- カテゴリ別ページ（コンテスト・授業・高大連携・IDERIA等）: categories.json から自動生成（1テンプレート）。

## 7. 学ぶ `/learn/`

- 学習トピック一覧（order順・レベル表示）。
- 各トピック: 解説（Markdown）＋サンプルコード表示（逆引きコード等をハイライト付きで表示）＋「この技術を使っている作品」自動一覧（games.learnTopics から逆引き）。
- 初期収録: 逆引きコード35本を分類した「逆引きコード集」＋入門トピック（ゲームループ・画像表示・キー入力・当たり判定など）。トピックはMarkdown追加のみで増やせる。

## 8. 年度別アーカイブ `/years/<year>/`

- games/activities の year から自動生成。年度内をカテゴリ別に区分して表示。

## 9. 共通

- ヘッダー: サイト名・主要ナビ（遊ぶ／作品／活動／学ぶ／About）・ダークモードトグル。
- フッター: サイト説明・カテゴリリンク・「IDERIA公式サイト」外部リンク（site.json のURLが空の間は**非表示**）。
- 404ページあり。パンくずあり（詳細ページ）。
- OGP/メタ: タイトル・description を各ページで設定。

## 10. 非機能

- JSはフィルタ・検索・テーマ切替・コードコピーのみ（軽量）。フレームワークランタイムなし。
- 画像は width/height 指定と loading="lazy"。
- すべての内部リンクはビルド時に静的生成されるため、リンク切れはビルドエラー/チェックで検出。
