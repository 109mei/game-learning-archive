## 3.7 掲載候補の確認結果（2026-09-04）

§3 の保留分を実際に開いて確認した。結論は次のとおり。

| 資料 | 確認したこと | 判断 |
|---|---|---|
| `オセロカードゲーム/IMG_1760.jpeg`（ボード） | 石畳テクスチャの6×6ボードのみ。人物・氏名・連絡先・背景の写り込みなし | **掲載可**。IDERIA公式サイトの作品一覧 No.05 の図版に採用 |
| `オセロカードゲーム/IMG_1761・1762.jpeg`（カード裏面） | 砂時計＋歯車の意匠のみ。人物・氏名・連絡先なし | **掲載可**（今回は未使用） |
| `卒論完成版/マニュアル表紙.png` | Python 2Dゲーム制作マニュアルの表紙。イラストは実在人物ではなく、氏名・連絡先・QRの記載なし | **氏名・連絡先の点では掲載可。ただし今回は登録を見送り**（下記の理由） |
| `卒論完成版/コンテストチラシ.png`（`コンテスト/十人十色コンテストチラシ.png` も同一内容） | 氏名・住所・電話・メールの記載はない。ただし「参加はコチラ↓」の **QRコードが `https://forms.gle/Fvdj2KoKxSm6zZ9u5`（Googleフォーム）に解決する** | **見送り**。応募フォームは実質的な連絡・受付窓口にあたり、恒久公開されるアーカイブに貼ると2024年の募集導線が再び有効になる |

**マニュアル表紙を `contest-2024` に登録しなかった理由**（プライバシーではなく、記述の正確さの問題）:

- マニュアル本体（`卒論完成版/マニュアル.pdf`・全27ページ）は **Python + Pygame** の汎用リファレンスで、十人十色コンテストへの言及がない。
- `contest-2024.json` の `tech` は `scratch` / `unity`、開催年は2024。いっぽう `マニュアル表紙.png` / `マニュアル.pdf` のファイル日付は **2025-03-19** で、`game-jam-pre`（2025-03-18・python/pygame・嘉穂総合高校）の翌日にあたる。
- したがってこの資料はコンテストではなく**ゲームジャム系の配布物**である可能性が高い。どの回の資料か確定できるまで `contest-2024` の `photos` には入れない。

**再開する場合の条件**:

- チラシ: QR部分をマスクした版を用意する、または応募フォームが閉じていることを確認する。
- マニュアル表紙: どの活動の配布物かを確定し、その活動のJSONに登録する（`game-jam-pre` などが候補）。

## 4. その他の確認結果

- パスワード・APIキー・アクセストークン・秘密鍵: 監査中のファイル名・拡張子ベースの走査では**発見されず**（.env や credentials 類なし）。ゲームのソースコードを公開用にコピーする際に、コード内へ機密や氏名が書かれていないか個別に確認する（WEB_COMPATIBILITY.md の作業と同時に実施）。
- `HILL_RUSH/save_data.json`・`machahunter/highscore.txt` 等のセーブファイル: 個人情報ではないが、公開用コピーでは初期状態に戻す。
- しまっぴー先生の覚えてクイズの `*.sav`: 公開対象に含めない。

## 5. サイト実装での対策

- サイトが読むデータは `game-learning-archive/site/src/data/` に**新規作成したJSONのみ**。研究フォルダを直接参照しない。
- ゲームのソース・素材は公開可否を確認した上で `site/public/` 配下へ**コピー**して使用（元ファイル不変）。
- 参加者名フィールドはデータ上 `creatorDisplay`（表示名）のみを持ち、本名リストは持たない。
