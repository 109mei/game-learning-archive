# SITE_PLAN.md — サイト情報設計

## 位置付け

「ゲームを遊んで、コードを見て、ゲーム制作を学べる **ゲーム制作・プログラミング学習アーカイブ**」。
IDERIA公式サイトでは**ない**。IDERIAは制作元・掲載元の一つ。フッターに「IDERIA公式サイト」外部リンク枠のみ用意（URLは site.json で空欄＝リンク非表示）。

対象読者: 中高生・大学生・ゲーム制作初心者・ゲームに興味がある人。

## ページ構成（URL設計）

| # | ページ | URL | 生成方法 |
|---|---|---|---|
| 1 | HOME | `/` | 固定＋データから新着・おすすめを自動表示 |
| 2 | ゲームを遊ぶ | `/play/` | `play.playable=true` の作品を自動一覧 |
| 3 | 作品一覧 | `/games/` | 全gamesから自動生成。絞り込み（年度・活動種別・ジャンル・技術・ブラウザ対応・制作元）＋タイトル検索 |
| 4 | 作品詳細 | `/games/<id>/` | games/*.json から自動生成 |
| 5 | 活動記録 | `/activities/` | 全activitiesから自動生成（カテゴリ・年度で絞り込み） |
| 6 | ゲームジャム一覧 | `/game-jams/` | category=game-jam を年度→開催回で自動一覧 |
| 7 | ゲームジャム詳細 | `/activities/<id>/` | activities/*.json から自動生成（全カテゴリ共通の詳細ページ） |
| 8 | ゲームコンテスト | `/contests/` | カテゴリ別一覧（自動） |
| 9 | 授業 | `/classes/` | 同上 |
| 10 | 高大連携 | `/collabs/` | 同上 |
| 11 | IDERIA制作作品 | `/ideria/` | 制作元=IDERIA の作品＋活動を自動一覧 |
| 12 | 年度別アーカイブ | `/years/` `/years/<year>/` | year から自動生成 |
| 13 | 学ぶ | `/learn/` `/learn/<slug>/` | content/learn/*.md から自動生成 |
| 14 | ソースコード閲覧 | `/source/<id>/` | game-sources/<dir>/ から自動生成（ファイルツリー＋ハイライト） |
| 15 | About | `/about/` | 固定 |
| - | プレイ実行ページ | `/play/<id>/` | ゲーム詳細から起動。iframe で pygbag ビルド(`/play-files/<id>/`)を分離表示 |

カテゴリページ(8〜11)は categories.json を元に**1つのテンプレートから自動生成**（カテゴリ追加＝JSONに1行でページも増える）。

## HOME 構成

1. ヒーロー: 「ゲームを遊んで、コードを見て、ゲーム制作を学ぶ」＋［今すぐ遊ぶ］［作品を見る］［学ぶ］
2. すぐ遊べるゲーム（playable上位）
3. 新着作品（createdDate/year降順）
4. 学習におすすめのゲーム（learnTopicsを持つ作品）
5. 最近の活動（ゲームジャム・授業・高大連携ほか）
6. カテゴリ導線カード（ジャム／コンテスト／授業／高大連携／IDERIA）

## 画面・UI方針

- カードUI・余白広め・詰め込みすぎない。ゲーム画面（サムネイル・プレイ画面）を大きく。
- レスポンシブ（PC/タブレット/スマホ）。カードは grid の auto-fill。
- 配色は CSS カスタムプロパティで一元管理し、`prefers-color-scheme` ＋手動トグルでダークモード対応。
- 見出し帯と本文ブロックには役割の違う色を割り当て、フォントは1書体系統（Noto Sans JP系）に統一。
- アクセシビリティ: セマンティックHTML・altテキスト・キーボード操作・コントラスト確保・`prefers-reduced-motion` 対応。
- サムネイル未整備の作品は「画像準備中」プレースホルダー（ジャンル別アイコン＋グラデ背景）。

## 遊ぶ〜学ぶの回遊動線

作品詳細 →「ブラウザで遊ぶ」→「ソースコードを見る」→「このゲームで使われている技術」→ 学習ページ → 学習ページから関連作品へ戻る。

## 技術選定（詳細は README）

**Astro** を採用。
- 比較: Next.js(React) は SPA/SSR 向きで静的アーカイブには過剰、GitHub Pages 運用に一手間。素のHTML手書きは大量ページで破綻。**Astro は「データ→静的ページ自動生成」が最短・出力が軽量・pygbag(iframe) 埋め込みも自由・GitHub Pages 無料公開可**。
- コンテンツはJSON/Markdown。ビルド: `npm run build` → `dist/` を GitHub Pages 等へ。
- pygame-ce → pygbag → WebAssembly のビルド成果物は `public/play-files/<id>/` に配置（サイト本体と分離、iframe 表示）。
